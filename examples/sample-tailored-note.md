# Sample tailored note

This is a demo outline only. It shows how tailoring works, it is not a real resume.

## Job

- Title: Data Analyst
- Company: Example Analytics Pvt Ltd (fake company)
- Location: Bangalore, India
- Experience: 0-2 years, in scope for auto-apply
- Posting: https://example-boards.test/jobs/demo-987654

## What tailoring does here

- Headline kept as: Data Analyst | SQL, Python, Power BI, Excel
- Skills highlighted, because they are on the resume and the job asks for them: SQL, Python, Excel, Power BI
- No skills invented. If the job asked for a skill not on the resume, that skill would be listed as a gap for a human call, and would not be added to the resume.

## Cover letter points

- 1-2 years of data analysis experience, in scope for this role.
- Matching skills above, with real project examples.
- Immediate joiner, based in Bengaluru, India.

## What is not in this file

No real resume text, no real company, no real applicant details. Run `python src/tailor.py examples/sample-job.json` to rebuild this outline from the sample job.
